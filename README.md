# 豬頭派對 Pig Party

一個「**等角大廳 ＋ 可插拔小遊戲**」的本地雙人派對遊戲。

兩個人在同一台電腦上一起玩小遊戲，**輸家會被變成豬頭** —— 頭變成粉紅豬頭、長出豬鼻和耳朵，連發出的聲音都變成豬叫。

大廳裡可以走動、換造型、看累計戰績；門就是選單，走到門前按確認就進小遊戲。

> 原始點子來自我們家大女兒。

## 線上玩

▶️ **https://pourquoiaimer.github.io/pig_party/**

需要鍵盤或手把。第一次點畫面才會開啟音效（瀏覽器的自動播放政策）。

## 玩法

| | P1（紅） | P2（藍） |
|---|---|---|
| 移動 | `W` `A` `S` `D` | `↑` `←` `↓` `→` |
| 確認／互動 | `Space` | `Enter` |
| 手把 | 左類比或十字鍵 ＋ `A` 鍵 | 同左（第二支手把） |
| 音樂開關 | `M` | `M` |

走到門前按確認鍵 → 進入該門的小遊戲。

## 本機執行

⚠️ **不能直接雙擊開啟**（`file://` 會被 CORS 擋掉 ES module，而且不會有明顯錯誤訊息）。要起一個 http server：

```bash
cd 豬頭派對
python3 -m http.server 8099
```

然後開 <http://localhost:8099>

## 技術選擇（為什麼這樣做）

**邏輯 2D、畫面 3D**
遊戲邏輯全部在平面 `(x, y)` 上算，再用 Three.js 的**正交相機**做等角投影。
好處：不用為了 8 個方向各畫一套 sprite，角色朝向只要轉個角度；物件前後遮擋交給 z-buffer 自動處理。

**門 ＝ 選單**
`MINIGAMES` 裡每個小遊戲實作同一組介面。大廳只知道「有幾扇門、門後面是誰」，完全不知道門後面在幹嘛。

**輸入抽象層**
遊戲邏輯只知道 `playerId`，不知道輸入是鍵盤還是手把。之後要接網路對戰，只要換掉輸入來源，遊戲本身不用改。

**音效全部程式合成，零音效檔**
用 Web Audio API 即時產生：
- `blip()` —— 三角波 ＋ 音量包絡（手把連接、2048 合併／死局、排球擊球與得分、換造型、重置）
- `pigSqueal()` —— 鋸齒波快速滑音穿過帶通濾波器、重複兩聲（豬叫）
- `footstep()` —— 低通濾波過的短噪聲，左右腳音高不同（走路時每 0.33 秒一次）
- `BGM` —— 五聲音階的緩慢琶音 ＋ 每 4 拍一個低音墊，用 `setInterval` 做前瞻排程

零版權問題，也零下載。`M` 鍵可開關音樂。

**戰績與造型存 localStorage**
`pigParty.record.v1` 存戰績、`pigParty.look.v1` 存每個人選的造型。
讀寫都用 try/catch 包起來（無痕模式或停用儲存時不會讓遊戲爆掉）。

**造型拆成兩個獨立的軸**
`BODIES`＝體型（男生／女生）、`TEAMS`＝隊伍顏色（紅／藍）。
換體型不會動到隊伍顏色。要加新身份就往 `BODIES` 加一筆，其他程式不用改。

## 怎麼新增一個小遊戲

1. 寫一個 `createXxx()`，回傳大廳要求的那組介面
2. 在 `MINIGAMES` 註冊
3. 在 `DOORS` 加一筆（位置、顏色、名稱、是否開放）

**大廳的程式完全不用動。**
