# 豬頭派對 Pig Party

一個「**等角大廳 ＋ 可插拔小遊戲**」的本地雙人派對遊戲。

兩個人在同一台電腦上一起玩小遊戲，**輸家會被變成豬頭** —— 頭變成粉紅豬頭、長出豬鼻和耳朵，連發出的聲音都變成豬叫。

大廳裡可以走動、換造型、看累計戰績；門就是選單，走到門前按確認就進小遊戲。

> 原始點子來自我們家大女兒。

## 線上玩

▶️ **https://pourquoiaimer.github.io/pig_party/**

需要鍵盤或手把。第一次點畫面才會開啟音效（瀏覽器的自動播放政策）。

## 玩法

| | P1（紅） | P2（藍） |
|---|---|---|
| 移動 | `W` `A` `S` `D` | `↑` `←` `↓` `→` |
| 確認／互動 | `Space` | `Enter` |
| 手把 | 左類比或十字鍵 ＋ `A` 鍵 | 同左（第二支手把） |
| 音樂開關 | `M` | `M` |

走到門前按確認鍵 → 進入該門的小遊戲。

## 大廳裡有什麼

| 東西 | 位置 | 做什麼 |
|---|---|---|
| 🚪 **門** | 北牆／東牆 | 走過去按確認 → 進入小遊戲（門＝選單） |
| 🪞 **更衣鏡** | 北牆右側 | 走過去按確認 → **切換自己的造型（男生／女生）**。只有自己會變，**隊伍顏色不變**，才認得出誰是誰。**變成動物期間不能換**——懲罰不能被鏡子洗掉 |
| 📊 **記分板** | 西牆 | 累計勝場、被變豬頭次數、總場次、平手次數 |
| 🔴 **重置鈕** | 西牆前的地板 | 走過去按確認 → **要按兩次**才會清空戰績（防誤觸） |

**每場結束後兩個小人會自動歸回原位**（並有 0.7 秒緩衝），
不然按著確認鍵、人又剛好站在門前，結算一結束就會直接開下一場。

**戰績與造型都會存在瀏覽器的 localStorage**，關掉分頁再開還在。

### 橫版對戰

| | P1（紅） | P2（藍） |
|---|---|---|
| 移動 | `A` `D` | `←` `→` |
| 攻擊 | `W` | `↑` |
| 防禦（按住） | `S` | `↓` |

- 血量 100，被打一下 **−14**；**按住防禦只扣 4**，擊退也變小
- 兩人**不能互相穿過**，而且**永遠面對對手**
- 血量歸零就**倒地**（整個人往後倒），等倒地動畫播完才進結算
- 角色直接用大廳那兩隻 —— **被變過頭的就用被變的頭去戰鬥**

#### 拳擊姿勢

角色手臂有**兩節關節**（肩 → 肘 → 手套），所以三種狀態長得不一樣：

**變身的狀態有兩個來源（`headKind` 和 `pigUntil`），兩者必須保持一致。**
判斷「還在變身中」一律看 `headKind`；只要出現「有頭但計時器已歸零」的狀態，
清計時器的迴圈不會清它、而重建角色的程式又不會保留它 —— 頭就會莫名消失。

| 狀態 | 肩膀 | 手肘 | 長相 |
|---|---|---|---|
| **放下** | −0.12 | −0.30 | 雙手自然垂在身側 |
| **防禦**（按住） | −0.35 | **−2.25** | **前臂抬到臉前護著**（拳擊護臉） |
| **攻擊** | → **−1.30** | → −0.27 | 手臂**打直往對手方向**，身體微前傾 |

出拳時**只有靠近相機那隻手打出去，另一隻手全程留在臉前護著**。
手套平常藏起來，上場才戴（P1 紅、P2 藍）。

**懲罰規則**：每場結束後比較分數，輸的一方（平手則不罰）**隨機被變成下面七種之一**，約 12 秒。

## 變身（輸家的懲罰）

輸的一方會隨機變成七種頭部之一 —— 全部是程式即時用幾何堆出來的，沒有模型檔：

| | 頭 | 特徵 |
|---|---|---|
| 🐷 | 豬頭 | 粉紅長鼻 ＋ 鼻孔 ＋ 三角耳 |
| 🐶 | 狗頭 | 前伸長吻 ＋ 黑色圓鼻 ＋ 兩片下垂軟耳 |
| 🐱 | 貓頭 | 三角尖耳 ＋ 短吻 ＋ 粉紅小鼻 ＋ 四根鬍鬚 |
| 🐔 | 雞頭 | 橘色尖喙 ＋ 三瓣紅冠 ＋ 肉垂 |
| 🦖 | 暴龍頭 | 上下顎 ＋ 嘴縫 ＋ 兩根後掠角 ＋ 六顆白牙 |
| 🐰 | 兔頭 | 兩根長豎耳（內側粉紅）＋ 短吻 ＋ 粉紅鼻 |
| 📺 | 電視頭 | 機殼 ＋ 發亮螢幕 ＋ 兩根天線（**會把頭顱藏起來**） |

**要再加一種**：往程式裡的 `HEADS` 表加一筆就好，其他程式完全不用動。

## 本機執行

⚠️ **不能直接雙擊開啟**（`file://` 會被 CORS 擋掉 ES module，而且不會有明顯錯誤訊息）。要起一個 http server：

```bash
cd 豬頭派對
python3 -m http.server 8099
```

然後開 <http://localhost:8099>

## 技術選擇（為什麼這樣做）

**邏輯 2D、畫面 3D**
遊戲邏輯全部在平面 `(x, y)` 上算，再用 Three.js 的**正交相機**做等角投影。
好處：不用為了 8 個方向各畫一套 sprite，角色朝向只要轉個角度；物件前後遮擋交給 z-buffer 自動處理。

**門 ＝ 選單**
`MINIGAMES` 裡每個小遊戲實作同一組介面。大廳只知道「有幾扇門、門後面是誰」，完全不知道門後面在幹嘛。

**輸入抽象層**
遊戲邏輯只知道 `playerId`，不知道輸入是鍵盤還是手把。之後要接網路對戰，只要換掉輸入來源，遊戲本身不用改。

**音效全部程式合成，零音效檔**
用 Web Audio API 即時產生：
- `blip()` —— 三角波 ＋ 音量包絡（手把連接、2048 合併／死局、排球擊球與得分、換造型、重置）
- `pigSqueal()` —— 鋸齒波快速滑音穿過帶通濾波器、重複兩聲（豬叫）
- `footstep()` —— 低通濾波過的短噪聲，左右腳音高不同（走路時每 0.33 秒一次）
- `BGM` —— 五聲音階的緩慢琶音 ＋ 每 4 拍一個低音墊，用 `setInterval` 做前瞻排程

零版權問題，也零下載。`M` 鍵可開關音樂。

**戰鬥：同一批 3D 角色 ＋ 另一台相機**
競技場蓋在離大廳很遠的地方（`x = 400`）。戰鬥時把兩個角色「搬」過去，並把 `activeCam` 換成側視相機。
因為角色是同一個物件，**「被變過頭的就用被變的頭去戰鬥」是免費的** —— 不用為此寫任何一行程式。
⚠️ 大廳的移動與桌子碰撞在戰鬥期間必須關掉，否則會把戰鬥中的角色拉走（`activeGame.ownsScene` 就是這個開關）。

**戰績與造型存 localStorage**
`pigParty.record.v1` 存戰績、`pigParty.look.v1` 存每個人選的造型。
讀寫都用 try/catch 包起來（無痕模式或停用儲存時不會讓遊戲爆掉）。

**造型拆成兩個獨立的軸**
`BODIES`＝體型（男生／女生）、`TEAMS`＝隊伍顏色（紅／藍）。
換體型不會動到隊伍顏色。要加新身份就往 `BODIES` 加一筆，其他程式不用改。

## 怎麼新增一個小遊戲

1. 寫一個 `createXxx()`，回傳大廳要求的那組介面
2. 在 `MINIGAMES` 註冊
3. 在 `DOORS` 加一筆（位置、顏色、名稱、是否開放）

**大廳的程式完全不用動。**
